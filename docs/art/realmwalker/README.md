# Realmwalker concept art

Images placed here appear in the **Realmwalker concept art** section of the Art page (`docs/art.html`).

1. Copy the images into this folder (PNG, JPG, WebP or GIF).
2. List them in `gallery.json`, in the order they should appear:

```json
[
  { "file": "wanderer-sketch.png", "title": "The wanderer", "note": "First pass at the silhouette." },
  { "file": "ruins-study.jpg", "title": "Ruins study" }
]
```

`title` and `note` are optional. Until the list has entries, the page shows empty frames.
